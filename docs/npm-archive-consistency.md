# Verified npm candidate archive (11.2F.2F)

Run `npm run test:archive`, then `npm run pack:verified` after a strict npm ci. The command regenerates dist using the accepted build pipeline, checks both declaration and bundle contracts, and produces a new temporary report directory outside the editor checkout. `npm run check:archive -- "<reported-directory>"` rechecks the current dist, actual gzip/TAR bytes, both npm pack metadata reports and the saved summary. The old root .tgz is not used or overwritten. This is a 1.0.0 test candidate, not a public release. Do not publish it.

The reader is intentionally limited to the current npm regular-file ustar format: no extraction, links, PAX/GNU extensions, path traversal, case collisions, executable entries, unexpected members or unbounded decompression (2 MiB compressed / 4 MiB expanded limits). The expected set is exactly 39 validated distribution files plus package.json, README.md and LICENSE. Every file is compared byte-for-byte, including license copies and the exact manifest. npm pack JSON name/version/size/count/SHA-1/SRI are cross-checked; the report additionally records SHA-256 and SHA-512 of the actual archive, file hashes, platform, runtime and manifest/lock hashes. Two packs from the same verified dist must be byte-identical. This does not assert reproducibility across npm versions, OSes or fresh builds. A checksum is not a signature or proof of provenance.

`npm run pack:verified -- --built` is for CI after a successful fresh build; it rechecks the current output rather than rebuilding. Default local command always rebuilds. `ARCHIVE_REPORT_DIR` may specify a new directory with an existing parent outside the checkout (never an existing directory). The runner never uses npm publish, changes versions, installs dependencies or updates the root lockfile. Do not edit the editor or dist concurrently. If a check fails, inspect the error and preserved diagnostics; do not weaken the inventory or bypass the gate.

Node build CI adds the 27 archive-contract tests, pack and independent re-verification in all six existing environments. It retains the archive, pack.json, repeat-pack.json, archive-summary.json and logs in each existing lane artifact. React and PHP workflows are unchanged. Raw npm pack/publish is not intercepted by this candidate helper; release automation is planned for 11.2G. Review source-map contents and legal notices again before release. Exact inventory excludes other files, but is not a scanner for secrets embedded in permitted files.
