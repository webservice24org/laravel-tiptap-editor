# 11.2F.3E — Links, colors and typography

Accepted baseline: F3D payload and 63 normalized source anchors; all 33 acceptance gates user-reported passed. Latest commit not supplied.

- Link dialog captures original document and range, edits selected link attributes without replacing selected text/marks, expands a cursor inside a link to its contiguous mark range, allows new text at a collapsed cursor, rejects changed documents. Selected link labels are read-only by design; use normal editing for label changes. Cancel does not modify the document; external host updates invalidate the snapshot. Only single-textblock selections are offered by the dialog. No general modal focus-trap overhaul (F7).
- Link validation permits HTTP/HTTPS, root-relative paths (not protocol-relative) and fragments. Bare dotted hosts are normalized only by the dialog. Existing mailto/tel/FTP are deliberately not supported because backend policy already rejects them. Core link validation is retained and narrowed, allowing bare host candidates for Linkify; persisted hrefs must be explicit URLs or supported relative references. Bare-host automatic linking retains the no-IP/no-single-word behavior. Browser policy does not promise exact URL parser equivalence with PHP. Target restricted to _self/_blank and blank gets noopener/noreferrer. Media URL policy unchanged.
- Independent custom marks use existing Tiptap core, no dependency change. Fixed color palette black/red/blue/green/purple, font size 12/16/20/24px, generic font family sans-serif/serif/monospace. Default removes the respective mark. Mixed/unset state uses a disabled placeholder. Existing general color sanitizer grammar remains; arbitrary color/font UI, highlights, external fonts and custom sizes are out of scope. Existing styles outside the new mark presets are not guaranteed editor round-trip. Server font-size/family rules only permit span and fixed values. No new attributes, CSS files, or public root exports.
- Thirteen new browser groups per React consumer, eight new static validator tests and three new PHP tests. All original browser groups required. Browser tests check live and saved HTML, link attributes and exact text, re-use accepted selection helper. Full installed runtime/build and PHP execution mandatory before acceptance.
