## Fix 1 — Native history focus isolation (966ec5a)

Both hosted consumers passed the previous 59 formatting groups and 11 of 12 history groups. Outside-editor history failed: the host input was focused, but editor HTML and callback both reverted from AXB to AB, and redo became available. Chromium reproduction on plain contenteditable demonstrates that keyboard focus and native undo event target can differ. The ProseMirror history plugin handles native historyUndo/historyRedo beforeinput events. The editor's direct handleDOMEvents.beforeinput guard now consumes those two event types when its view does not own focus, preventing plugin execution and cancelling browser default when cancelable. Focused native events, all other input types and host inputs are not intercepted. No document-level listeners are installed in production. A noncancelable native event cannot be cancelled by JavaScript; this guard does not guarantee isolation from arbitrary browser DOM mutations.

Keep the same 12 required history groups. Check editor HTML, callback count, focus and history availability after each external shortcut separately. Exercise independent native host input undo/redo and re-enter editor to confirm its original history remains usable. Capture native beforeinput delivery in test diagnostics only.
