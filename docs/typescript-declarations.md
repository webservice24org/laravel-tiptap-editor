# TypeScript declaration contract — 11.2F.2C

This phase keeps TypeScript 5.9.3, React/Tiptap peer ranges, Vite and the accepted lockfile unchanged. It does not publish a package. Source checking remains strict with Bundler resolution and existing upstream skipLibCheck; missing side-effect imports are now checked. The obsolete, unreferenced `resources/js/Index.tsx` is explicitly excluded; `resources/js/index.ts` is the public entry. No runtime component or Vite configuration changes are made.

`npm run build` cleans dist, bundles JS/CSS, emits declarations, normalizes their relative specifiers to `.js`, and checks the complete declaration inventory and public API. `npm run build:types` is for a clean declaration output tree; prefer the full build if old declaration maps are present. Declaration maps are disabled because the published package does not ship the original TS source and normalizing imports would invalidate maps. JavaScript source maps are unchanged.

The AST-based declaration normalizer resolves every relative declaration reference against the exact generated file inventory; it removes only the known side-effect source CSS import from TiptapEditor.d.ts. It does not change the JS bundle or CSS export, and rejects other missing relative references, undeclared package names, unexpected declaration maps or colliding output names. It preserves the existing four public value exports and nine public types and adds five type-only exports for custom nodes, ensuring their three Tiptap command augmentations are reachable. The public API fixture uses the package name and checks named/default editor, sanitizer, extension factory, props, upload/news callbacks, command types and six expected compile-time errors.

`npm run check:types` verifies the generated graph and runs a strict Bundler consumer compiler check (including dependency declarations, skipLibCheck false) plus a NodeNext consumer smoke check (skipLibCheck true for upstream library declarations; own relative references are independently verified). This does not certify Node runtime imports of browser code, React 18 runtime support, or every external declaration under NodeNext. CSS is still separately exported; no new CSS type export is promised. React 18/19 consumer matrix belongs to F2E.

`npm run test:types` runs 19 validator unit tests. All six existing Node/OS CI lanes now run these tests, source checking, full build and declaration checks. The declaration-summary.json artifact records file sizes and hashes; a green workflow, not the report alone, establishes successful type checking. PHP CI is unchanged.

Do not commit dist, tgz files or composer.lock. Keep any existing old dist/archives outside the project before running the full build if they need to be retained. No npm publish or version change in this phase.
