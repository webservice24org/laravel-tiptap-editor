# React consumer compatibility (11.2F.2E)

The editor root lock remains unchanged. Test two standalone apps, React/React DOM 18.3.1 (types 18.3.12/18.3.0) and React/React DOM 19.3.1 (types 19.3.0). Tiptap 3.32.0, Vite 7.3.8 and TypeScript 5.9.3 are held fixed; Playwright 1.65.1 is consumer-only. The separate Ubuntu Node 24 CI matrix has two required lanes and an aggregate gate. Existing PHP and six-lane Node workflows are unchanged.

## Local

Run `npm run test:consumer:contract`, `npm run build`, then `npm run test:consumer -- 18` and `npm run test:consumer -- 19` individually. The latter commands need registry and Playwright browser download access and a supported Node version. On Linux outside hosted CI, install browser OS dependencies separately if required. No root dependency installation/update, global npm change or publication occurs in these commands. The root build cleans dist; back it up before building if needed. The work directory is outside the project, with separate node_modules and a generated lock. The registry is explicitly npmjs.org. Direct versions are fixed; transitive versions are freshly resolved in each run and recorded, then installed using npm ci. Do not describe this as a precommitted frozen consumer lock. Never bypass strict peer or engine checks to pass a lane.

The runner verifies the root declarations/bundle, packs into a temporary directory with lifecycle scripts disabled, checks the pack inventory and hash, installs the real archive rather than a symlink, verifies all 39 dist files byte-for-byte, checks singleton lock paths and installed versions for the two React packages, React types, 32 Tiptap packages, and other selected packages. ProseMirror lock entries may not be nested. It runs both audits, strict Bundler and NodeNext smoke checks (upstream lib checking skipped only in NodeNext as in F2C), a Vite consumer build, and Chromium browser smoke: public exports, sanitizer/factory, actual named editor mount, CSS, initial content, callback, unmount and default export remount. Browser errors and nonlocal requests fail. Warnings are recorded. This is not exhaustive browser/security/toolbar or SSR testing. It is not a release archive.

Evidence is printed in a temporary report directory (or a new directory selected by CONSUMER_REPORT_DIR outside the project). Successful work directories are removed; failed work is retained for troubleshooting. Reports include actual consumer lock, package inventory, audits, logs, archive hash, dist hashes and browser summary. Review reports for sensitive paths or registry information before sharing. GitHub evidence retained 14 days. Do not commit temporary archives, dist, or consumer lock reports. Keep final evidence for F2G.
