# Changelog

## 1.0.0 — release candidate

- Laravel 12 and 13 compatibility, with PHP platform requirements verified by the compatibility matrix.
- Hardened server-side media ownership, upload authorization, storage lifecycle and HTML sanitization.
- React 18 and 19 support; Node 22, 24 and 26 within declared engine constraints.
- Formatting, history, links, image/media, tables, videos and News Blocks regression coverage.
- Inert source highlighting and controlled Visual/Code synchronization; responsive table scrolling and dialog keyboard focus improvements.
- Frozen dependency checks, npm archive integrity verification and paired React CI evidence.

This candidate is not published until all release gates pass. No MWT application migration is part of this release.
